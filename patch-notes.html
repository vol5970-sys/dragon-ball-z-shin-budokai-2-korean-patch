CHANGELOG · V0.8

패치 노트

v0.8은 정적 검증을 마친 QA43 빌드를 배포 버전으로 정리한 패치입니다.

반영 범위

  • 팀 편성, 부스터 앨범, 카드 편집, 전투 일시정지 메뉴, 결과 화면, 게임 설정과 확인 버튼의 한국어 UI.
  • 필드 결과 라벨, 프로필 능력치, AR_EVTEST의 테스트·디버그 텍스트 14개.
  • 카메라 미리보기 16개: 각도 라벨과 인게임 캐릭터 이름을 한국어로 보정.

확인 사항

xdelta 패치를 지정 원본 ISO에 복원해 완성 ISO의 SHA-256이 기대값과 일치하는지 확인했습니다.

남은 범위

  • 엔딩 크레딧 그래픽에 직접 그려진 일본어 스태프·성우 표기.
  • 일부 로고와 타이틀 이미지에 포함된 일본어 텍스트.
