최신 메뉴·팀 편성 수정 내용을 반영한 xdeltaUI용 패치입니다. 원본 게임 ISO와 실행 프로그램은 포함하지 않습니다.

## 준비물

- 본인이 보유한 원본 ISO
- xdeltaUI
- 이 배포본의 `DBZ_Shin_Budokai_2_Korean_v0.9.xdelta`

원본 ISO는 아래 크기와 SHA-256이 일치해야 합니다. 이미 한글 패치를 적용한 ISO에는 다시 적용하지 마세요. ISO의 파일 이름은 달라도 됩니다.

## xdeltaUI 적용 방법

1. 배포 ZIP의 압축을 풉니다.
2. xdeltaUI를 실행하고 **Apply Patch** 화면을 엽니다.
3. **Patch**에서 `DBZ_Shin_Budokai_2_Korean_v0.9.xdelta`를 선택합니다.
4. **Source File**에서 위 SHA-256과 일치하는 원본 ISO를 선택합니다.
5. **Output File**에서 새 ISO를 저장할 위치와 이름을 정합니다. 권장 이름은 `Dragon Ball Z Shin Budokai 2 Korean v0.9.iso`입니다. 원본과 다른 파일을 지정하세요.
6. **Patch / Apply Patch** 버튼을 눌러 적용합니다. 사용하는 xdeltaUI 버전에 따라 버튼 이름이 다를 수 있습니다.
7. 적용 후 새 ISO의 크기와 SHA-256을 확인합니다.
8. 게임을 완전히 종료하고 새 ISO로 실행합니다. 이전 ISO의 세이브 스테이트를 불러오면 이전 화면 상태가 남을 수 있습니다.

## 이번 수정 내용

- 메인 메뉴 일곱 항목의 글자 크기·굵기·높이와 외곽선 통일.
- 아케이드, Z 트라이얼, 프로필 카드, 옵션 및 세부 설정 메뉴의 검은 잔여 글자와 네모 배경 정리.
- 메뉴 제목 배너 23개 정리.
- 팀 편성의 캐릭터 이름 25개를 선택·비선택 두 상태 모두 다시 제작하고 밝기 개선.
- 팀 편성 제목의 이미지 합성 흔적 정리.
- 전투 일시정지 메뉴 네 항목의 중심 정렬 조정.
- 이전 빌드의 번역과 엔딩 그래픽 반영 내용을 유지.

오른쪽 부스터 카드, 숫자 카드, 화살표는 원본 게임의 그림과 일치하여 원래 디자인을 유지했습니다.

## 확인 범위

패치를 원본 ISO에 실제 적용한 뒤 결과가 v0.9 빌드와 완전히 같은지 검증했습니다. 수정된 게임 자원에서 이미지를 다시 추출하여 글자·배경·투명도를 확인했습니다.

이번 배포 작업에서는 에뮬레이터·실기 플레이 검증을 하지 않았습니다. 실제 화면에서 잘림, 정렬, 팔레트 문제가 남아 있으면 화면과 사용한 ISO의 SHA-256을 함께 기록해 주세요.

## 오류가 발생할 때

- `source file mismatch` 또는 체크섬 오류: 원본 ISO의 SHA-256을 확인합니다. 다른 판본이나 이미 패치된 ISO를 사용하면 적용되지 않을 수 있습니다.
- 출력 파일 생성 오류: 원본과 다른 파일 이름을 지정하고 저장 위치의 쓰기 권한과 여유 공간을 확인합니다.
- 이전 그래픽이 계속 표시됨: 실행 중인 게임을 종료하고 QA49 출력 ISO를 다시 선택합니다.

파일별 SHA-256은 `checksums.txt`, 수정 내역은 `RELEASE_NOTES.md`를 참고하세요.
