APPLY PATCH

xdeltaUI 적용 방법

  1. 다운로드한 ZIP의 압축을 풉니다.
  2. xdeltaUI에서 Patch에 DBZ_Shin_Budokai_2_Korean_v0.8.xdelta를 선택합니다.
  3. Source File에 해시가 일치하는 원본 ISO를 선택합니다.
  4. Output File을 지정한 뒤 Apply Patch를 누릅니다.

이 배포본은 정적 검증을 통과했습니다. 이번 빌드 단계에서는 에뮬레이터·실기 런타임 검증을 하지 않았습니다.
